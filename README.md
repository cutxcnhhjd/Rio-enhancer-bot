# Video Enhancer Telegram Bot

This is a simple Telegram bot that automatically enhances the quality of anime or game-style videos. Powered by AI-based video upscaling (similar to Topaz).

## Features
- Accepts video uploads via Telegram
- Automatically enhances and upscales the video
- Sends the improved video back to the user
- Fully automatic and AI-powered

## How to Use
1. Start the bot on Telegram.
2. Send a video.
3. Wait for the bot to process and return the enhanced version.

## Tech Stack
- Python
- Telegram Bot API
- FFmpeg / AI upscalers
- Hosted on Render

## Setup (For Developers)
1. Clone the repo.
2. Add your Telegram Bot Token to `.env`.
3. Deploy using Render or Replit.
